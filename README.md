
# Secure Software Systems - Group 13

## Electronic Voting Platform (EVP)

RMIT University
INTE2667 - Secure Software Systems
Assignment 3 - Group Project

## Project Overview

This repository contains the group implementation of
an Electronic Voting Platform (EVP) with security
controls for authentication, authorisation, ballot
protection, and secure voting operations.

## Technology

- Programming Language: Python
- Backend Framework: To be finalised by the group
- Testing: Automated security and functionality tests
- Version Control: Git and GitHub

## Development Workflow

Each group member will implement their allocated
security requirements using a separate feature branch.

Completed features will be tested and reviewed
before integration into the main branch.
